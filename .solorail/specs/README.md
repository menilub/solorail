# Issue Specification Files

Each issue under development gets its own spec file: `<ISSUE-ID>-spec.md`.

**Naming:** `E01-ISS-01-spec.md` or `BUG-01-spec.md`

**Contents:**
- Acceptance Criteria (copied from Epic)
- Technical Design (minimal, only what's needed)
- Allowlisted Files (which files the issue may touch)
- Test Plan (RED-GREEN-REFACTOR cycle outline)
